# Master — платформа онлайн-записи

Демо интерфейса: https://edu.china.kg. Полное приложение находится в этом репозитории; текущий FTP workflow публикует только `preview/index.html`.

## Рабочий первый этап

Laravel 12 + Inertia 2 + React 19 + TypeScript + Tailwind 4.

- Регистрация мастера, вход и выход; защищённый кабинет.
- Создание и редактирование услуг, цены и длительности, отключение услуг.
- Недельное расписание с выходными и часовым поясом мастера.
- Публичная страница `/m/{slug}` и запись клиента без регистрации.
- Свободные слоты с шагом 30 минут, автоматическое или ручное подтверждение.
- Подтверждение, отмена и завершение записей в кабинете.
- Серверная проверка рабочих часов, блокировок и пересечений. MySQL-транзакция с блокировкой строки мастера сериализует конкурирующие бронирования.
- Ограничение частоты входа/регистрации/записи, CSRF и изоляция данных мастеров.

## Локальный запуск

Нужны PHP 8.2+, Composer 2, Node 22 и SQLite либо MySQL 5.7+.

```sh
composer install
cp .env.example .env
php artisan key:generate
touch database/database.sqlite
php artisan migrate
npm ci
npm run build
php artisan serve
```

Откройте `/register`. Учётные записи и реальные клиенты не добавляются сидером; паролей по умолчанию нет. Времена записей хранятся в UTC, отображаются в часовом поясе мастера (по умолчанию Asia/Bishkek).

## Проверки

```sh
php artisan test
npm run check
npm run build
```

CI повторяет проверки на MySQL 5.7 и 8.0, включая конкурентное бронирование двумя отдельными процессами. Локально на SQLite этот тест пропускается: SQLite не доказывает работу MySQL row locks.

## Публикация

`deploy-preview.yml` автоматически загружает изменения `preview/` из `main` в изолированный FTP-корень `/`, проверяет файл обратным скачиванием и сравнивает его с HTTPS-страницей домена. FTP-пользователь должен быть привязан непосредственно к `/home/n66843/public_html/edu.china.kg`.

Для серверного приложения нужен отдельный безопасный deploy: web root только `public/`, `.env`, `vendor/`, `storage/` и код вне публичного каталога. См. `docs/deployment-jaz.md`. Не загружайте весь репозиторий в FTP-корень текущего демо.

## Дальнейшие этапы

Полный календарь, перерывы и исключения в расписании через кабинет, карточки и история клиентов, уведомления и восстановление пароля, роли администратора, эксплуатационные резервные копии. Текущая версия — первый запускаемый этап, не весь продукт.

Серверный архив автоматически создаётся workflow `Build server release` и сохраняется в GitHub Actions как `master-server-release` (ZIP + SHA-256). Это сборка без `.env` и dev-зависимостей; она не устанавливается на сайт автоматически. Фактический PHP домена сейчас 8.1.34: перед установкой необходимо выбрать 8.3 в cPanel.
