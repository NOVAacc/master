# Master — платформа онлайн-записи

Временный адрес: `https://edu.china.kg`.

## Продукт

Платформа персональных страниц и онлайн-записи для частных специалистов.

### MVP

- Профиль мастера с персональным публичным адресом
- Каталог услуг (стоимость и продолжительность)
- График работы и блокировки времени
- Публичная запись без регистрации
- Подтверждение и отмена заявок
- Управление клиентами и историей записей
- Административная панель

## Планируемый стек

Laravel + Inertia.js + React + TypeScript + Tailwind CSS + shadcn/ui, MySQL. Конкретные версии определяются после проверки PHP на JAZ.

## Хостинг

JAZ (shared hosting); способ деплоя ещё не проверен. Ничего не публиковать без настройки безопасного document root, переменных окружения и резервных копий.
