# Публикация демонстрации Master на JAZ

Демо-страница находится в файле `preview/index.html` репозитория `NOVAacc/master`.

## Первый безопасный запуск

1. В панели JAZ откройте файловый менеджер для поддомена `edu.china.kg`.
2. Проверьте, какая папка назначена корнем сайта. Не используйте папку другого сайта.
3. Если в этой папке уже есть `index.html` или `index.php`, сначала сохраните резервную копию. Не перезаписывайте файлы без проверки.
4. Загрузите содержимое `preview/index.html` как `index.html` **только в пустую или специально выделенную папку** поддомена.
5. Откройте `https://edu.china.kg` и проверьте страницу с телефона и компьютера.

Это только автономный интерфейс с демонстрационными данными. База данных не используется.

## Для автоматической публикации

Нужны адрес FTPS-сервера, имя пользователя и **точный удалённый путь корня поддомена**. Данные авторизации следует хранить в GitHub Actions Secrets, а не в исходном коде и не в переписке.

Автоматический деплой пока не включён. Перед его настройкой нужно подтвердить путь, проверить SSL и исключить удаление чужих файлов.

## Для полноценного Laravel

PHP 8.3 доступен. MySQL 5.7 не соответствует требованиям Laravel 12; необходима поддерживаемая внешняя БД либо смена среды. Сначала тестируем приложение локально или в CI, а затем публикуем на подходящей инфраструктуре.
