# Публикация демо Master

Демо `preview/index.html` автоматически загружается из `main` через `.github/workflows/deploy-preview.yml` при изменении `preview/` либо самого workflow. Также доступен ручной запуск из GitHub Actions.

- Explicit FTPS: `hostch01.fornex.org`, порт 21; проверка сертификата включена.
- FTP-пользователь изолирован корнем сайта `/home/n66843/public_html/edu.china.kg`; внутри FTP используется `/`.
- Секреты GitHub: `MASTER_FTP_USER`, `MASTER_FTP_PASSWORD`. Устаревший `MASTER_FTP_DIR` больше не используется.
- После загрузки файл скачивается обратно и сравнивается с исходником. Затем HTTPS-страница `https://edu.china.kg` сравнивается с ним побайтно. `Index of /` вызывает ошибку CI.

Демо опубликовано и проверено 16 октября 2026. Оно автономно, с вымышленными данными и без подключения к БД. Этот workflow не публикует Laravel-приложение.

Для серверной публикации см. `deployment-jaz.md`: document root должен указывать только на `public/`; остальные файлы должны быть приватны. Laravel 12 поддерживает MySQL 5.7+, PHP требуется 8.2+. Тесты приложения включены в отдельный CI.
