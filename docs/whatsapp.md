Отправитель BOSH: **+996 550 512 233** (решение владельца от 17.10.2026). Номер уже используется в приложении WhatsApp Business. Регистрация в Cloud API, Phone Number ID, токен и одобрение шаблонов пока не подтверждены; автоматическая отправка в production выключена.

Номер хранится в `WHATSAPP_SENDER_NUMBER` и может быть изменён без редактирования кода. Это номер телефона, а не `WHATSAPP_PHONE_NUMBER_ID`: последний выдаёт Meta. Для замены отправителя нужно также зарегистрировать новый номер в Meta и обновить его ID/доступ токена; изменение одного отображаемого номера не переключает API.

Уведомления всем мастерам и клиентам отправляются от BOSH. Мастеру достаточно указать свой номер и согласиться на уведомления; ему не требуется собственный API-аккаунт. Подтверждение владения номером мастера ещё не реализовано.
Кнопка в подтверждённой записи мастера открывает сообщение клиенту; клиент после создания заявки видит итог и кнопку сообщения мастеру, если в профиле заполнен телефон. Открытие ссылки не означает отправку: пользователь нажимает «Отправить» в WhatsApp самостоятельно.

## Подключение автоматической отправки

Нужны WhatsApp Business Platform / Cloud API, зарегистрированный бизнес-номер отправителя, постоянный access token, Phone Number ID и два одобренных шаблона на русском. Номер получателя у мастера задаётся в «Моя страница → Телефон». Мастер включает получение уведомлений; клиент отдельно выбирает получение подтверждения в WhatsApp.

Значения из `.env.example` задаются только в приватном `/home/n66843/master-app/shared/.env`. Токен не хранить в Git, интерфейсе или журналах. `WHATSAPP_API_VERSION` — поддерживаемая версия Graph API из Meta Dashboard, например формата `vNN.0`; в коде версия не зафиксирована. Включить `WHATSAPP_ENABLED=true` только после теста бизнес-номера и одобрения шаблонов. Деплой сохраняет существующий приватный `.env`. При включённом config cache выполнить `php artisan config:clear`.

Создать utility-шаблоны с body-параметрами в точности в таком порядке:
1. Имя клиента.
2. Имя мастера.
3. Услуги.
4. Дата в часовом поясе мастера.
5. Начало–конец и часовой пояс.
6. Общая сумма в сомах.
7. Адрес или «Уточните у мастера».
8. Контакт: телефон мастера для клиента; телефон клиента для мастера.

Подтверждение вручную и автоподтверждение используют одну интеграцию. Уведомления не создаются для ожидающих заявок, без согласия получателя или для прошлых записей. Старая клиентская база не получает согласие автоматически. Отмена и напоминания пока не реализованы.

## Переносы и правки

Изменения времени, длительности, услуг, стоимости или контакта создают новую версию уведомления подтверждённой записи. Старые принятые или неопределённые попытки не повторяются; запросы старой версии блокируются. При включённом канале и действующем согласии отправляются актуальные данные через те же шаблоны. Рекомендуемая формулировка шаблона: «Актуальные данные подтверждённой записи».

Правка одного комментария не отправляет повторное подтверждение. При смене номера клиента прежнее согласие сбрасывается; на новый номер автоматическое сообщение не уходит. Ручная кнопка WhatsApp в кабинете всегда содержит текущие данные.

## Состояния

- `not_configured`: канал не подключён; ничего не отправлялось.
- `recipient_changed`: номер получателя изменился после создания уведомления; сообщение на прежний номер не отправляется.
- `sending`: запрос выполняется, повторный запрос не запускается.
- `accepted`: Meta вернула ID сообщения; это не подтверждение доставки или прочтения.
- `failed`: API явно отклонил запрос (4xx); мастер может повторить отправку, максимум 5 попыток.
- `unknown`: таймаут, 5xx или неожиданный ответ. Отправка могла произойти, поэтому автоматический и ручной повтор через сайт блокируются до проверки результата у провайдера.

Webhook доставки и фоновый планировщик повторов ещё не подключены. Повторы явных отказов выполняются владельцем записи из кабинета. Приложение не обещает доставку по одному успешному HTTP-ответу.

## Однократная активация владельцем BOSH

1. Войти в Meta Business / WhatsApp Manager от владельца BOSH и выбрать либо создать бизнес-портфолио.
2. Подключить +996 550 512 233 к WhatsApp Business Platform. Для номера в приложении WhatsApp Business сначала проверить доступность официального режима совместной работы (Coexistence) у выбранного провайдера/в потоке Meta; не удалять текущий WhatsApp и не переносить номер вслепую.
3. Создать и отправить на одобрение два utility-шаблона выше (`ru`, восемь параметров). Окончательная категория и одобрение определяются Meta.
4. Настроить оплату в Meta/у провайдера, получить Phone Number ID и доступ Cloud API. Токен вводится только в приватные серверные настройки; не передавать его в чате.
5. Указать поддерживаемую версию Graph API. Выполнить согласованный тест на номерах владельца, проверить фактическое получение и затем включить канал.

Наличие приложения WhatsApp Business на номере само по себе не активирует Cloud API. До завершения настройки продолжает работать ручная отправка через ссылки WhatsApp.
