# Состояние Master

## Реализовано

Запускаемый Laravel 12 / Inertia / React / TypeScript проект, регистрация/вход/выход, кабинет мастера, услуги, недельное расписание, публичные страницы, выбор свободного времени и бронирование, ручное/автоматическое подтверждение, отмена и завершение. Цены и названия сохраняются в записи как снимок. Все временные отметки записей — UTC.

Проверяются принадлежность услуги мастеру, активность, будущее время, рабочие часы с учётом часового пояса, полная длительность услуги, блокировки и занятые интервалы. Обновления расписания/услуги и бронирования используют блокировку одной строки мастера. Закрытая отменённая запись не может быть открыта заново поверх новой записи.

Веб-тесты проверяют авторизацию и изоляцию кабинетов, приватность публичной страницы, бронирования, соседние интервалы, выходные, отключённые услуги, блокировки, согласие и контакты, расписание. Отдельный тест запускает два процесса против MySQL для проверки конкуренции. TypeScript и production-сборка включены в CI.

## Публикация

16 октября 2026 серверное приложение опубликовано на https://edu.china.kg через workflow `Deploy Master application`, run 38916889542, revision 6d76e9f5f2d872e16fb8d7f879bb59747258babc. База подключена, миграции выполнены после резервной копии. Проверены `/login`, `/register`, `/up`, главная и недоступность `.env`, vendor/autoload.php и storage/logs/laravel.log. Временные загрузки и установщик удалены.

На домене подтверждён PHP 8.3.33 с явным обработчиком LiteSpeed. Новые releases из `main` публикуются автоматически после успешных тестов, сборки и интеграционных проверок установки/отката. Статическое демо больше не публикуется автоматически.

## Осталось

Визуальный календарь, карточки клиентов и история, UI исключений/перерывов, восстановление пароля, уведомления, администрирование, эксплуатационный мониторинг и резервное копирование. Эксплуатационные настройки, приватный каталог, серверный `.env`, резервная копия перед миграциями и проверки отката настроены.

## Сборка серверного релиза

Workflow `Build server release` создаёт приватный GitHub artifact `master-server-release` с ZIP и SHA-256. В архив не включаются `.env`, тесты, node_modules, рабочие логи и кэши. Перед публикацией отдельно проверяются шифрованная установка, обновление, сохранение ключа/storage, отклонение повреждённого архива и откат на MySQL 8.0.
